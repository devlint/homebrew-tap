# GitWand Homebrew tap

Install [GitWand](https://gitwand.app) — the Git client that auto-resolves merge conflicts — on macOS:

```bash
brew install --cask devlint/tap/gitwand
```

That's shorthand for `brew tap devlint/tap && brew install --cask gitwand`.

The desktop app is signed & notarized; the cask auto-updates via GitWand's built-in updater.
Source & other platforms (Linux, Windows, CLI, VS Code, MCP): https://github.com/devlint/GitWand
